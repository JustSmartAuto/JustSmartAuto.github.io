技术专题：ViDi EL Classify 与 EL Segment 的应用边界

发布日期：2026-05-24 ｜ 分类：技术专题

在某马达产线系列方案（共 17 个检测工位）中，Cognex ViDi 深度学习的两个工具被大量使用： EL Classify（蓝色分类工具）与 EL Segment（红色分割工具）。 本文结合项目实践，总结两者的分工边界、组合策略与常见误判风险。

一、工具定位

EL Classify：图像级「是什么」的判断

  • 对整个图像或关注区域输出一个类别标签（OK / NG / 正反 / 型号……）。
  • 训练成本低，适合类别差异明显、不需要定位缺陷位置的场景。
  • 典型应用（本项目）：马达上料防混料、胶盖铁盖正反与混料识别、点油「有无」判断、介子有无安装。

EL Segment：像素级「在哪里、有多少」的分析

  • 对缺陷或目标区域做像素级分割，可输出面积、位置、尺寸等量化的检测结果。
  • 适合缺陷形态不规则、需要定量判定（如油量达标线）的场景。
  • 典型应用（本项目）：各处点油的油量测量、热压热铆点划痕/变形/毛线缺陷、铁齿轮压痕裂痕尺寸测量、圆形端面展开后的点油检测。

二、组合策略：交叉验证降低误判

本项目反复出现的一个模式是「Classify 判有无 + Segment 判多少」双工具协同：

  • 涡轮杆点油：EL Segment 测油量，EL Classify 判有无，两者结果交叉验证；
  • 胶齿轮侧面金属柱：Classify 判有无，Segment 判油量是否达标；
  • 介子工位：有无安装（Classify）与漏加油脂（Segment）一次拍照双重判定。

这样做的好处是：Classify 提供了稳定的「全局兜底」，Segment 提供了量化阈值， 当油量处在达标线附近时，两个工具结果不一致可以直接触发人工复核，而不是简单放行或误杀。

三、常见误判风险与工程对策

风险出处对策
点油量过少时被误判为 OK多处点油工位均注明「过少有误判风险」与点油工艺联动保证下限；双工具交叉验证；NG 样品充分入库训练
金属原色背景导致误判率升高介子工位强制黑色背景打光；必要时加光源控制器稳定亮度
换型后工作距离变化导致成像漂移全部工位换型规范：相机/镜头/光源到产品的工作距离保持不变；按产品号调用检测程序
拍照震动引入运动模糊全部工位机构拍照位需稳定、不可大震动；线扫工位要求旋转同轴度 > 0.2

四、选型速查

  • 只关心「对不对 / 有没有 / 是哪款」→ EL Classify；
  • 关心「缺多少 / 在哪里 / 多大尺寸」→ EL Segment；
  • 两者都需要 → 先 Classify 兜底，再 Segment 定量；
  • 定位与角度一律交给 PatMax 图案匹配，不要让深度学习干几何的活。
